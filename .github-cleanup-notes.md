## 🔄 Para contribuidores

Se você clonar o repositório:

1. **Gere os dados:**
   ```bash
   cd co-piloto-quant
   python scripts/build_dna_b3.py
   python scripts/data_pipeline.py
   ```

2. **Instale dependências:**
   ```bash
   # Backend
   pip install -e co-piloto-quant
   
   # Frontend
   cd co-piloto-frontend
   npm install
   ```

3. **Inicie o sistema:**
   ```bash
   # Terminal 1
   python api_backend.py
   
   # Terminal 2
   cd co-piloto-frontend
   npm run dev
   ```
