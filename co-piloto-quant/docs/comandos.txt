# Guia de Comandos Essenciais

Este arquivo serve como um guia rápido para executar as principais funcionalidades do projeto Co-Piloto Quant.

## Fluxo de Trabalho Padrão

O fluxo de trabalho moderno e recomendado consiste em duas etapas simples:

1.  **Atualizar os Dados e Rodar o Scanner**: Um único comando para garantir que todos os dados de mercado estejam atualizados e para gerar a análise de todos os ativos.
2.  **Visualizar no Dashboard Interativo**: Lançar o painel Streamlit para analisar os resultados de forma interativa.

---

### Etapa 1: Atualizar o Banco de Dados e Rodar o Scanner

Este é o comando central do sistema. Ele faz o seguinte:
- Baixa os dados mais recentes para **todos os ativos** listados no `config.py`.
- Salva e atualiza os dados no banco de dados local (`market_data.db`).
- Calcula todos os indicadores técnicos.
- Aplica as regras de análise e gera o `score` para cada ativo.
- Salva o resultado em `scanner_results.csv`.

**Comando:**
`python scripts/run_scanner.py`

**Importante:** Execute este comando diariamente antes de abrir o mercado para garantir que sua análise está baseada nos dados mais recentes.

---

### Etapa 2: Visualizar a Análise no Dashboard

Após rodar o scanner, utilize o dashboard interativo para explorar os resultados.

**Comando para lançar o dashboard:**
`streamlit run run_streamlit.py`

**O que o dashboard oferece:**
- Uma tabela com todos os ativos analisados, seu `score` e `Tendencia Macro`.
- Filtros para encontrar rapidamente os ativos mais promissores (ex: score > 3).
- Gráficos detalhados para cada ativo, mostrando o preço e os principais indicadores.

Este novo fluxo substitui os antigos scripts `run_pipeline.py` e `run_dashboard.py`, oferecendo uma maneira muito mais eficiente e poderosa de analisar o mercado.
