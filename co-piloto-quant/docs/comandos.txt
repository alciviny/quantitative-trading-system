# Guia de Comandos Essenciais

Este arquivo serve como um guia rápido para executar as principais funcionalidades do projeto Co-Piloto Quant.

## Fluxo de Trabalho Padrão

O fluxo consiste em duas etapas principais: primeiro, processar os dados de um ativo e, em seguida, visualizar a análise.

---

### Etapa 1: Gerar os Dados Processados

Este comando baixa os dados brutos do mercado, realiza a limpeza e os cálculos necessários, e salva o resultado em um arquivo `.csv` na pasta de dados processados.

**Comando:**
`python scripts/run_pipeline.py --ticker SEU_ATIVO.SA`

**Exemplo Prático:**
Para processar os dados da Vale (VALE3), use:
`python scripts/run_pipeline.py --ticker VALE3.SA`

---

### Etapa 2: Visualizar a Análise

Após gerar os dados na Etapa 1, você tem duas opções para visualização.

#### Opção A: Dashboard Padrão

Este comando carrega os dados processados e exibe o painel de análise técnica padrão.

**Comando:**
`python scripts/run_dashboard.py --ticker SEU_ATIVO.SA`

**Exemplo Prático:**
`python scripts/run_dashboard.py --ticker VALE3.SA`

---
#### Opção B: Visualização Flexível de Indicadores

Este script permite gerar um gráfico com uma combinação personalizada de indicadores. É útil para análises mais focadas.

**Comando Base:**
`python scripts/visualize_indicator.py --ticker SEU_ATIVO.SA [INDICADOR_1] [INDICADOR_2] ...`

**Argumentos:**
- `--ticker`: Define o ativo a ser analisado (obrigatório).
- `[INDICADORES]`: Lista opcional (separada por espaços) de indicadores a serem exibidos. Se omitido, todos os indicadores padrão serão mostrados.
  - Opções disponíveis: `price`, `ifr`, `obtr`, `wad`, `stoch_custom`.

**Exemplos Práticos:**

1.  **Visualização padrão para PETR4.SA (todos os indicadores):**
    `python scripts/visualize_indicator.py --ticker PETR4.SA`

2.  **Visualizar apenas o Preço e o Estocástico para VALE3.SA:**
    `python scripts/visualize_indicator.py --ticker VALE3.SA price stoch_custom`
