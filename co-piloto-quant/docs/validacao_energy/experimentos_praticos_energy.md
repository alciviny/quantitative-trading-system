# Experimentos Práticos — Sinal de Energy

## 1. Refinamento Contínuo
- Script para grid search automatizado de quantis, janelas e horizontes.
- Template para análise visual dos resultados (heatmaps, linhas de AUC/alpha_top).

## 2. Combinação com Outros Sinais
- Script para combinar energy com momentum, volume e volatilidade relativa.
- Pipeline para testar filtros compostos e comparar métricas.
- Exemplo de uso do energy como feature em modelo supervisionado (regressão logística).

## 3. Aprendizado Contínuo
- Template de documentação automática dos experimentos.
- Script para geração de relatórios comparativos após cada grid search.

## 4. Expansão e Generalização
- Script para aplicar o pipeline de energy em diferentes universos de ativos.
- Template para análise de robustez e adaptação dinâmica de thresholds.

---

**Os scripts e templates serão implementados e salvos em `/co-piloto-quant/scripts/` e `/docs/validacao_energy/` para fácil acesso e versionamento.**
